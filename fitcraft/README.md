# HERACLES LAB · 健身秘典

六部位传统健美训练互动课程：胸、背、肩、腿、手臂、核心，全部开放。共 24 关、60 道带解析情境题、24 个动作与 6 张可交互解剖图。保留原奇幻卡牌冒险，并新增训练计划设计毕业章。

## 本地运行

```sh
python -m http.server 4173 --directory dist
```

打开 http://localhost:4173/ 。网站无构建、包管理器或服务端依赖。全部图片、字体回退、JavaScript、CSS 与题库均为本地资源；外部文献仅为可选阅读链接。

## 课程与功能

每个部位均有解剖探索、动作实验、强度控制、训练编排四关。图中肌肉可以点击和放大，深层结构通过明确标注的窗口展示；动作图有起止位置与路径。每关附完整可展开的中文知识讲解、情境题和即时解释。

编排按部位分别检查动作数、工作组数、动作模式、RIR 和休息。例如背部要求水平拉与垂直拉，下肢要求蹲与髋铰链，手臂包含屈肘和伸肘，核心包含抗伸展与抗旋转。数量范围仅为单堂教学案例，不是每周处方。

支持六章独立进度、全课程错题复习、60 条学习笔记、6 枚徽章、24 题综合挑战、3 天/4 天每周编排思路与文本下载。Service Worker 在首次完整加载后缓存本地资源，支持离线复习。离线能力需 HTTPS 或 localhost，首次资源尚未缓存时无法保证可用。

## 动作选择、进阶与计划设计

六部位的动作实验新增选择实战：按目标、器械条件、稳定与舒适度比较方案；24 个动作都提供角色、替代选项和选择依据。强度关增加针对本部位的进阶原则。

第七章位于六部位课程之后，包含：

- 9 条原则：动作选择、渐进超负荷、逐次线性加重、双重进阶、线性周期、频率、总量、恢复和记录。
- 三种条件性进阶模拟与真实表现判断。输入全部工作组次数、最低 RIR、质量与恢复，决定加重、维持、回退或停止；疼痛提示优先于数字校验。
- 5 套完整周案例：全身三练、推拉腿三练、推拉腿六练、上下肢四练、经典五分化。三分化与每周次数分开解释，五分化不被描述为更高级。
- 7 天自编计划：增删、排序、跨日移动动作，设置组数、次数区间、RIR、休息、每动作进阶规则、起始负荷、最小增量和负荷口径。可以从案例开始或新建空白，并撤销最近修改。
- 按部位分开显示直接组与部分常见间接参与，检查主要模式、训练与休息日、相邻日重叠与努力程度。结构通过不代表个人适用性或效果保证。
- 6 个计划情境判断、12 道结课题、4 项实操任务与独立结课徽章。每动作条件可直接带入模拟，计划可导出为 TXT / JSON。

线性加重保持固定目标次数；双重进阶先达各组上限再加重。模拟仅展示条件满足的路径，未达标时可能重复原节点；线性周期的三周变化加一周减量只是演示。自重练习记录版本与控制，不把难度当成公斤。

## 进度兼容

新进度保存到浏览器 localStorage `fitcraft-academy-v2`；首次升级自动迁移同源 `fitcraft-chest-v1`。支持六章 JSON 完整导入导出，也兼容旧版 `heracles-chest` 备份。计划设计进度独立保存在 `fitcraft-planning-v1`，动作选择保存在 `fitcraft-selection-v1`。学习笔记的完整备份同时包含三部分，新版本导入旧备份时保留其没有携带的新章节状态。计划本身另有独立 JSON / TXT 导出。

原版 `classic.html` 继续使用 `fitcraft-v1`，与课程进度独立。

不同域名、浏览器或设备不能自动共享 localStorage，请从“我的学习笔记”导出后在目标站点导入。导入完整备份会恢复备份中的六章状态；导入旧胸部备份仅替换胸部，保留其他章节。

## 文件

- `dist/index.html`、`academy.js`、`academy.css`：多章节交互与界面。
- `dist/courses/*.js`：六章结构、正文、题库、编排规则。
- `dist/chest-data.js`：兼容保留的胸部基础数据。
- `dist/assets/*-anatomy.svg`、`exercise-*.svg`：本地原创解剖和动作示意。
- `dist/classic.html`、`game.js`、`questions.js`、`style.css`：原卡牌游戏。
- `dist/course-enrichment.js`、`selection-lab.js`：六部位选择与进阶补充。
- `dist/planner-data.js`、`planner-engine.js`、`planner.js`、`planner.css`：计划内容、纯逻辑与交互。
- `dist/sw.js`、`manifest.webmanifest`：按部署子路径隔离的离线缓存与安装信息。

## 部署

现有 GitHub Pages 地址：https://heracles1983.github.io/heracles-science-quest/fitcraft/ 。将 `dist/` 内容放到该仓库的 `fitcraft/`，保留根项目。具体操作见 DEPLOYMENT.md。
