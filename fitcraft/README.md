# 健身秘典 · HERACLES LAB

[进入游戏](https://heracles1983.github.io/heracles-science-quest/fitcraft/)

原创奇幻卡牌健身科普小游戏：力量、营养、恢复三章，18道知识挑战。支持知识解析、来源链接、三种英雄秘术、知识图鉴、错题复习和刷新续玩。

本目录是独立静态网站，所有游戏运行资源都来自本站，无构建步骤、无外部字体或 JavaScript CDN。

本地运行：`python -m http.server 4173`，打开 `http://localhost:4173`。

进度保存在当前浏览器。游戏内生命、护盾和伤害仅用于玩法，不代表现实训练、饮食或恢复效果。

源版本：`f143395516db6c720bc2ce751a48f611ff72f715`。
